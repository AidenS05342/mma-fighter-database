About

About This Project

Fight Ledger is a static, front-end demonstration of a combat sports analytics interface. It runs entirely in the browser with HTML, CSS, and vanilla JavaScript. It has no servers, APIs, or tracking.

Data Notice

Fighter data comes from official UFC.com athlete profiles and the UFC Record Book. Records and win methods cover each fighter's full professional career; striking and grappling figures cover UFC bouts only. Nothing is estimated: a value UFC.com does not list is shown as N/A. Refresh the data with python -I tools/update_fighters.py.
